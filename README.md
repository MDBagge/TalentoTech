# La Forja de Velkarys

Tienda artesanal de accesorios y elementos para juegos de rol en la mesa. Dados de resina, cuadernos y objetos de coleccionismo hechos a mano.

🔗 Sitio publicado: [Enlace pendiente de deploy]

## Páginas
- `index.html`: Página principal con el catálogo de productos (grilla de inventario) y reseñas de aventureros.
- `taller.html`: Bitácora del artesano donde se detalla el proceso de fabricación, materiales y filosofía de trabajo.
- `contacto.html`: Formulario de consultas y encargos personalizados conectado a Formspree.

## Tecnologías
HTML5 semántico, CSS3 (con Flexbox, CSS Grid y variables nativas) y Formspree para la gestión de formularios.
